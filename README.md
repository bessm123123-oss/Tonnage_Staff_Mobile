# TONNAGE Mobile

Мобильный Android-дневник тренировок TONNAGE.

Текущая стабильная ветка: **v0.11.0**.

Основной исходник: `App.tsx`.

Ключевые возможности текущей версии:
- тренировки, подходы, повторы и тоннаж;
- упражнения с внешним весом и собственным весом;
- папки упражнений;
- планы и календарный график;
- таймер отдыха и локальные уведомления;
- рекорды, достижения, статистика и архив;
- завершение отдельного упражнения по ходу тренировки;
- возобновление случайно завершённой тренировки;
- обмен с Windows-штабом через `.tonnage` и `.tonnage-db`.

## Сборка APK

```bash
cd ~/workout-log
EAS_SKIP_AUTO_FINGERPRINT=1 npx eas-cli@latest build -p android --profile preview
```

Android package: `com.diesel.workoutlog`.
